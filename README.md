# RealmEconomyShop — Paper 1.16.5

پلاگین اقتصاد و فروشگاه گرافیکی با هدف Paper 1.16.5 و Java 8.

## قابلیت‌ها
- `/shop` فروشگاه دسته‌بندی‌شده و صفحه‌بندی‌شده.
- در اولین اجرا، فهرست قیمت برای تمام `Material`های موجود در API سرور ایجاد می‌شود؛ بنابراین منبع فهرست با نسخه واقعی Paper 1.16.5 هماهنگ است و نام متریال نسخه‌های جدیدتر به‌صورت دستی وارد نشده است.
- قیمت خرید/فروش، فعال‌بودن، دسته‌بندی و وضعیت مجازبودن هر متریال در `config.yml`.
- `/money`, `/money <player>`, `/pay <player> <amount>`.
- `/eco give|take|set|view <player> [amount]` با مجوزهای جداگانه.
- ذخیره موجودی در `players.yml` و ذخیره دوره‌ای.
- Nether Star تنظیمات مستقل دارد.
- GUI امن: کلیک‌های منو لغو می‌شوند؛ هیچ آیتمی از خود GUI قابل برداشتن نیست.
- خرید با کلیک چپ (۱)، Shift+کلیک چپ (۱۶)، فروش با کلیک راست (۱)، Shift+کلیک راست (۱۶). فروش فقط از موجودی بازیکن انجام می‌شود.
- در منوی آیتم، کلیک چپ خرید و راست فروش است؛ برای معامله دسته‌ای از Shift استفاده کنید.

## ساخت JAR از گوشی اندروید (بدون نصب ابزار روی گوشی)
1. در GitHub یک repository بسازید.
2. فایل‌های ZIP را استخراج و **محتویات پوشه** را در ریشه repository آپلود کنید؛ پوشه `.github/workflows` را هم حفظ کنید.
3. در تب **Actions**، workflow با نام `Build RealmEconomyShop` اجرا می‌شود. پس از موفقیت، در بخش Artifacts فایل ZIP خروجی workflow را دریافت کنید؛ داخل آن JAR قرار دارد.
4. JAR را در پنل MagmaNode در مسیر `plugins/` آپلود و سرور را کامل restart کنید.
5. در اجرای اول، پلاگین بخش `shop.prices` را برای متریال‌های سرور تولید می‌کند. سپس سرور را متوقف کنید، قیمت‌ها را در `plugins/RealmEconomyShop/config.yml` تغییر دهید و دوباره اجرا کنید.

## ساخت محلی
با JDK 8 و Maven:
```bash
mvn clean package
```
خروجی: `target/RealmEconomyShop-1.0.0.jar`

## تنظیمات قیمت‌ها
ساختار تولیدشده برای هر متریال:
```yaml
shop:
  prices:
    DIAMOND:
      enabled: true
      category: STONE
      buy: 250.0
      sell: 100.0
```
مقادیر `buy` و `sell` باید عددی و نامنفی باشند. `enabled: false` آیتم را از خریدوفروش خارج می‌کند. `unpriced-item-policy: DENY` هر آیتم فاقد قیمت را غیرقابل معامله می‌کند؛ `USE_DEFAULT` برای آیتم فاقد قیمت از قیمت پیش‌فرض استفاده می‌کند.

## نکات و محدودیت‌ها
- پوشش مواد به `Material.values()` همان Paper runtime متکی است. متریال‌های صرفاً بلوکی یا فنی ممکن است در GUI قابل معامله نباشند؛ آیتم‌های فنی در فهرست `restricted-materials` قرار دارند و قابل تنظیم‌اند.
- اقتصاد داخلی است و به Vault وابسته نیست.
- حفاظت ضدتکثیر Nether Star به‌صورت سیستم معامله امن و تنظیم مستقل ارائه شده؛ پلاگین ادعا نمی‌کند که جلوی همه روش‌های تکثیر ناشی از باگ‌های دیگر پلاگین‌ها/سرور را می‌گیرد.
- تجهیزات PvP، کلنگ ۳×۳ و تبر ویژه در این نسخه فعال/پیاده‌سازی نشده‌اند تا اولویت روی اقتصاد و فروشگاه پایدار بماند.
- پس از ویرایش config، سرور را restart کنید. همیشه پیش از ارتقا از `plugins/RealmEconomyShop/` نسخه پشتیبان بگیرید.
